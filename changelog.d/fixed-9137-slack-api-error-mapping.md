- Slack `missing_scope` / `not_allowed_token_type` errors from socket setup and message sends are no longer reported as "chat topic updates unsupported": only `conversations.setTopic` maps them to the topic-capability error, every other call now surfaces the actual Slack error code with token/scope guidance, and config validation now rejects an enabled `notifications.slack` block whose `app_token` does not start with `xapp-` or whose `bot_token` does not start with `xoxb-` — the swapped-token mistake that produced the misleading message ([#9137](https://github.com/hivecommons/hive/issues/9137)).
