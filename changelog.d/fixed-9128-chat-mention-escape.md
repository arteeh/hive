- Outbound chat messages no longer let untrusted text (issue titles, agent summaries) trigger mentions: the Slack chat bot escapes mrkdwn control characters (`&`, `<`, `>`) outside code spans so `<!channel>`/`<!here>`/`<@U…>` render literally, and only turns markdown links into Slack links for HTTP(S) URLs; Discord bot messages and Discord notification webhooks disable mention parsing (`allowed_mentions`) so `@everyone` and role/user mentions no longer ping the channel, and Discord bot messages now suppress link embeds as the webhook already did ([#9128](https://github.com/hivecommons/hive/issues/9128)).
