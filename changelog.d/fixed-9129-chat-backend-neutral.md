- The shared chat spine no longer presents itself as a Discord bot on every transport ([#9129](https://github.com/hivecommons/hive/issues/9129)). The online banner and `!help` header now name the backend actually in use (`Hive chat bot online (slack)`), and spine log lines are prefixed `chat:` with a `backend=` attribute instead of `discord:`. Dashboard errors echoed by `!kick`/`!pause`/`!resume` are now bounded to the first line of the response body, capped at 200 bytes with control characters stripped, so an HTML error page or stack trace no longer lands verbatim in the channel. The Slack backend no longer logs `slack socket disconnected … use of closed network connection` on every clean shutdown.
